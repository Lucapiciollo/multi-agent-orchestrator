# Personal libraries integration

La skill deve valutare le librerie personali dell'utente.

## plDynamicForm

Usare per:

- form dinamici;
- filtri;
- stepper;
- combo remote;
- multi checkbox;
- nested form;
- configurazioni JSON/TS.

## jx-cell / jxcel

Usare per:

- spreadsheet;
- planner;
- griglie editabili;
- celle;
- tabelle evolute;
- dati a matrice.

## ux-design / ux-directives / ux-utils

Usare per:

- direttive comuni;
- loading;
- empty state;
- skeleton;
- tooltip;
- helper visuali;
- utility.

## Regola anti fake import

Non inventare import. Cercare prima package, public-api ed esempi nel workspace.
