# Responsive Skill

## Obiettivo

Rendere responsive esclusivamente la libreria assegnata.

## Regole

- Analizzare ogni componente separatamente.
- Preferire flexbox e Bootstrap grid/utilities.
- Non alterare il layout desktop già approvato.
- Non modificare componenti esterni alla libreria.
- Usare scroll orizzontale solo quando la riduzione compromette leggibilità o funzionalità.
- Evitare larghezze fisse non motivate.
- Gestire testo lungo, toolbar, tabelle, dialog e form.
- Conservare accessibilità e ordine semantico.

## Risoluzioni minime

- 375x667
- 390x844
- 768x1024
- 1024x768
- 1440x900

## Output

- SCSS modificati.
- Report dei problemi.
- Screenshot prima/dopo.
- Problemi residui dichiarati.
