# Installazione

## ChatGPT / Codex

Copia la cartella `pl-enterprise-angular-agent` nella directory delle skill del tuo ambiente, mantenendo intatta la struttura.

Struttura attesa:

```text
pl-enterprise-angular-agent/
├── SKILL.md
├── INSTALL.md
├── agents/
│   └── openai.yaml
└── references/
```

Dopo l'installazione riavvia o ricarica l'ambiente che gestisce le skill.
