# Responsive breakpoints

La skill deve verificare almeno questi viewport:

```txt
360x740   mobile stretto
390x844   mobile moderno
430x932   mobile grande
768x1024  tablet portrait
1024x768  tablet landscape
1366x768  desktop comune
1440x900  desktop
1920x1080 full desktop
```

Breakpoint SCSS suggeriti:

```scss
$bp-xs: 360px;
$bp-sm: 480px;
$bp-md: 768px;
$bp-lg: 1024px;
$bp-xl: 1280px;
$bp-xxl: 1440px;
```
