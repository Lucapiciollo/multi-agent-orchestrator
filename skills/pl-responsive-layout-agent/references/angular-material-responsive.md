# Angular Material responsive notes

## Mat table

Le `mat-table` complesse devono spesso restare larghe e avere wrapper scrollabile.

## Mat dialog

Su mobile il dialog deve diventare quasi fullscreen.

## Mat form field

Nei form mobile ogni `mat-form-field` deve occupare il 100% della riga.

## Mat toolbar

Le toolbar Material spesso hanno `display:flex` ma non sempre `flex-wrap`.
Controllare sempre wrap e min-width.
