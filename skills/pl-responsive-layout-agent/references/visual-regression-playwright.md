# Visual regression Playwright

La skill può usare Playwright per:

- screenshot multi viewport;
- rilevare overflow globale;
- rilevare elementi fuori viewport;
- distinguere scroll globale da scroll locale controllato;
- verificare desktop dopo patch.

Viewport minimi:

- 360x740
- 390x844
- 430x932
- 768x1024
- 1024x768
- 1366x768
- 1440x900
- 1920x1080
