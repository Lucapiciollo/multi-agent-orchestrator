# Playwright Validation Skill

## Obiettivo

Validare comportamento e fedeltà visuale tramite browser reale.

## Regole

- Avviare l'applicazione con comando documentato.
- Navigare tutte le route assegnate.
- Testare le risoluzioni previste.
- Catturare screenshot stabili.
- Verificare overflow, elementi tagliati e sovrapposizioni.
- Verificare errori console e richieste fallite.
- Non aggiornare snapshot per nascondere regressioni.
- Riportare differenze con pagina, selettore e risoluzione.
