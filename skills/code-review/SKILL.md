# Code Review Skill

## Responsabilità

- Controllare build, lint e test applicabili.
- Verificare che le modifiche siano nello scope.
- Cercare regressioni, duplicazioni e dipendenze circolari.
- Verificare typing, error handling e separazione delle responsabilità.
- Verificare che i criteri di accettazione siano realmente soddisfatti.
- Non correggere automaticamente problemi architetturali senza dichiararlo.
- Classificare i problemi: critical, high, medium, low.

## Approvazione

Un task è approvato solo se:
- build riuscita;
- nessun errore critico;
- nessun file fuori scope;
- criteri obbligatori verificati;
- problemi residui documentati.
